# 📥 100% Direct Instagram Reels Downloader

**કોઈ બીજી વેબસાઇટ નહીં — ઝીરો રિડાયરેક્ટ!**

### 🚀 કેવી રીતે વાપરવું:

1. **`start_server.bat` પર ડબલ-ક્લિક કરો:**
   * આ તમારા કમ્પ્યુટર પર લોકલ ડાઉનલોડર સર્વર શરૂ કરશે અને આપમેળે તમારા ક્રોમ/બ્રાઉઝરમાં સાઇટ ખોલશે (`http://127.0.0.1:5000`).
2. **ઇન્સ્ટાગ્રામ રીલની લિંક પેસ્ટ કરો.**
3. **"વિડીયો બતાવો"** પર ક્લિક કરો.
4. **"ડાયરેક્ટ વિડીયો ડાઉનલોડ કરો (Save MP4)"** પર ક્લિક કરો.
   * બસ! કોઈ નવું ટેબ નહીં ખુલે અને કોઈ બીજી સાઇટ નહીં આવે — સીધી જ `.mp4` ફાઇલ તમારા **Downloads** ફોલ્ડરમાં ડાઉનલોડ થઈ જશે!
